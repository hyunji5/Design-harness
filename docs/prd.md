# 공간 행사 운영 도구 PRD (쉬운 버전)

2026-09-28

쇼핑몰이나 백화점에서는 1년 내내 여러 행사가 열려요. 이 문서는 그 행사를 준비하는 사람을 돕는 프로그램을 무엇으로, 어떻게 만들지 정리한 계획서예요.

## 1. 한 줄 정의

**공간 행사 캘린더는 쇼핑몰·백화점의 행사 담당자가 행사 날짜 바꾸기, 참여할 가게 고르기, 손님용 게임 준비를 한 화면에서 쉽게 하도록 돕는 프로그램이다.**

## 2. 주요 사용자

**쇼핑몰이나 백화점에서 행사를 맡은 마케팅 담당자예요.** 이 사람은 한 건물에서 1년 동안 여러 행사를 준비해요. 행사에 참여하는 가게, 무대와 안전을 맡은 직원, 돈 계산을 맡은 직원과 함께 일해요.

**지금 가장 힘든 점:** 필요한 자료는 이미 다 있어요. 그런데 자료가 여러 곳에 흩어져 있어서, 뭔가 바뀔 때마다 하나하나 다시 맞춰야 해요.

- 행사 날짜가 바뀌면 설치 시간, 일할 사람, 홍보, 가게에 보낼 안내, 돈 계산 마감일을 모두 따로따로 다시 확인해요.
- 참여할 가게를 뽑을 때 빠진 서류, 조건에 맞는지, 비슷한 가게가 겹치는지, 예전에 참여한 적이 있는지를 여러 파일을 뒤져 비교해요.
- 손님이 즐길 게임을 따로 만들고, 행사 일정과 또 맞춰야 해요.

## 3. 사용자 시나리오

### A. 행사 날짜가 바뀌었을 때

1. 담당자가 달력에서 행사를 새 날짜로 끌어서 옮겨요.
2. 프로그램이 함께 바뀌어야 할 일을 한 화면에 모아 보여줘요. 설치 시간, 일할 사람, 가게 안내, 돈 계산 마감일이 여기에 들어가요. 같은 장소에 다른 행사가 겹치는 것 같은 문제도 알려줘요.
3. 담당자가 하나씩 확인하고, 고칠 것은 고친 뒤 "적용"을 눌러요.
4. 관련된 직원과 가게에 바뀐 내용이 자동으로 전달돼요.

### B. 행사에 참여할 가게를 고를 때

1. 담당자가 참여 조건과 필요한 서류를 정하고 신청서를 열어요.
2. 신청이 들어오면 AI가 서류가 빠졌는지, 조건에 맞는지, 비슷한 가게와 겹치는지를 나눠서 보여줘요. 왜 그렇게 판단했는지 이유도 같이 보여줘요. 예전 기록이 없으면 "기록 없음"이라고 솔직하게 표시해요.
3. 헷갈리는 신청은 담당자가 직접 다시 보고 합격, 보류, 불합격을 결정해요.
4. 뽑힌 가게는 자리, 준비 일정, 알림에 자동으로 연결돼요.

### C. 손님용 게임을 준비할 때

1. 담당자가 이미 만들어진 게임 틀 중에서 하나를 골라요.
2. 브랜드 그림, 문구, 기간, 경품을 넣고 휴대폰 웹페이지에 올려요.
3. 손님은 앱을 깔지 않고 휴대폰으로 행사 안내를 보고, 게임을 하고, 경품에 응모해요.
4. 행사가 끝나면 담당자가 몇 명이 참여했는지 같은 결과를 내려받아 보고서와 다음 행사 계획에 써요.

## 4. 만들 화면

1. 행사 달력
2. 행사 상세 화면 (준비 일정, 마감일, 날짜가 바뀌면 영향받는 일)
3. 가게 신청 심사 화면
4. 게임 설정 화면
5. 손님용 휴대폰 화면

## 5. 꼭 지킬 것 / 하지 않을 것

**꼭 지킬 것**

1. **AI는 이유를 보여주고, 결정은 사람이 해요.** AI가 가게를 마음대로 떨어뜨리거나 게임을 마음대로 올리지 않아요.
2. **날짜를 바꾸면 관련된 일이 하나도 빠짐없이 보여야 해요.** 담당자가 확인하기 전에는 아무것도 바뀌거나 전송되지 않아요.

**하지 않을 것**

1. **돈을 직접 받거나 영수증(세금계산서)을 발행하는 기능은 만들지 않아요.** 돈 계산은 "언제까지 확인해야 하는지" 날짜만 알려줘요.
2. **회사가 이미 쓰는 프로그램을 대신하거나, 손님 한 명 한 명의 정보를 모아 광고에 쓰지 않아요.** 참여 결과는 손님이 동의한 범위 안에서, 전체 숫자로만 써요.

## 어려운 말 풀이

| 말 | 뜻 |
| --- | --- |
| PRD | 무엇을 만들지 정리한 제품 계획서 |
| 시나리오 | 사용자가 프로그램을 쓰는 순서를 이야기처럼 적은 것 |
| 정산 | 행사가 끝난 뒤 주고받을 돈을 계산하고 마무리하는 일 |
| 입점사 | 행사에 참여해 물건을 파는 가게나 브랜드 |
| 모바일 웹 | 앱 설치 없이 휴대폰 인터넷으로 여는 화면 |
